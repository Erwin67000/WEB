## 2. Données collectées

Selon l’usage du Site :

- **Identité et contact** : nom, prénom, e-mail, adresse postale, téléphone s’il est fourni, société et n° TVA si commande professionnelle.
- **Commande et fabrication** : configuration (cotes, modules, finitions), SKU, messages, contraintes de livraison.
- **Paiement** : lorsque Stripe sera activé, le prestataire traitera l’instrument de paiement. ATELIER PHILAE recevra un statut (payé / échoué) et un identifiant de transaction, pas le numéro de carte. Tant que Stripe n’est pas ouvert, le paiement se fait hors Site (virement / consignes par e-mail).
- **Livraison** : adresse (y compris le pays, pour déterminer l’éco-participation française), instructions d’accès.
- **Échanges** : e-mails, SAV, photos de défauts éventuellement envoyées.
- **Technique** : logs CDN (Cloudflare) : adresse IP, user-agent, pages consultées, horodatage.
- **Préférence de langue** : mémorisée localement (voir [politique cookies](/politique-cookies)).
- **Newsletter** : e-mail, uniquement en cas d’inscription volontaire (opt-in).

**Google Fonts.** Le Site charge les polices Oswald et Stardos Stencil depuis les serveurs de Google (`fonts.googleapis.com`, `fonts.gstatic.com`). Google peut collecter l’adresse IP. Ce n’est pas un traitement interne d’ATELIER PHILAE.

Aucun pixel Meta, aucun Google Analytics n’est déployé à ce jour.

## 4. Destinataires

- Personnel / dirigeant d’ATELIER PHILAE.
- Prestataire de paiement **Stripe**, uniquement lorsque le paiement en ligne sera activé.
- Hébergeur / CDN : **Cloudflare, Inc.**
- Transporteur, communiqué avant livraison.
- **Ecomaison** (éco-organisme DEA) : déclarations de mises sur le marché pour les livraisons en France, pas le fichier client complet.
- **CM2C**, si une médiation est ouverte.
- Expert-comptable, éventuel avocat, assurances, autorités (sur réquisition).
- Google (Fonts), tant que les polices ne sont pas auto-hébergées.

## 5. Transferts hors UE

Cloudflare, Inc. a son siège aux États-Unis. Stripe, lorsqu’il sera activé, peut traiter des données hors UE, encadré par ses mécanismes contractuels (CCT / DPF selon documentation). Google Fonts : connexion vers des serveurs Google, souvent hors UE.

## 6. Durées de conservation

- Commandes, factures, garanties : durée d’exécution + **5 à 10 ans** (obligations comptables).
- Messages sans commande : **3 ans** à compter du dernier contact utile.
- Newsletter : jusqu’au désabonnement.
- Logs techniques : quelques jours à quelques semaines, sauf incident.
- Préférence de langue : voir politique cookies.
