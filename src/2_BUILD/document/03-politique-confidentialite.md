# Politique de confidentialité

Dernière mise à jour : 25 août 2026.

**ATELIER PHILAE** (SASU, 28 rue Kuhn, 67000 Strasbourg — contact@philae.design) utilise vos données pour répondre, fabriquer, livrer et facturer : identité, contact, adresse, configuration de la pièce. Lorsque le paiement en ligne sera ouvert, il sera traité par Stripe ; nous ne conservons pas les numéros de carte.

La **newsletter** n’est envoyée qu’après une inscription volontaire. Elle n’est pas requise pour commander. Désinscription à tout moment, via le même bouton ou par e-mail.

La fréquentation du Site est mesurée avec **Plausible** (statistiques agrégées, sans cookie publicitaire). L’adresse e-mail n’est pas transmise à Plausible.

Nous ne vendons pas vos données. Elles sont partagées seulement avec qui est nécessaire : atelier, transporteur, Cloudflare, Plausible, et Stripe le moment venu. Pour une livraison en France, l’éco-participation est déclarée à Ecomaison.

Conservation : commandes selon les obligations légales ; newsletter jusqu’au désabonnement.

Vos droits (accès, rectification, effacement, opposition) s’exercent à contact@philae.design. Réclamation : [CNIL](https://www.cnil.fr).
